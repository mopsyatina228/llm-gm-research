# LLM Game Master Research

Исследование методов, которыми уже пытались сделать LLM пригодными для роли игрового мастера (GM/DM) в TTRPG и долгих интерактивных RPG.

Главный вывод исследования: зрелые системы обычно не пытаются хранить весь канон в параметрах модели. LLM отвечает за повествование, интерпретацию действий и поведение NPC, а состояние мира, правила, память, ограничения и проверки выносятся во внешние структуры.

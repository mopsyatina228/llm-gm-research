# Источники

Ссылки ниже фиксируют найденные во время первичного исследования материалы. Даты и численные результаты следует перепроверять перед публикацией как формальный обзор.

## Misty

GitHub: https://github.com/mltheuser/misty-public

Основной интерес: self-play/grounded data, continued pre-training, fine-tuning и специализированное GMing.

## FIREBALL

Hugging Face dataset: https://huggingface.co/datasets/lara-martin/FIREBALL

Основной интерес: игровые транскрипты + структурированное состояние + механика D&D.

## D&D Dungeon Master: Narrative Style Transfer

GitHub: https://github.com/akashdatageek/D-D-Dungeon-Master-Narrative-Style-Transfer-by-Fine-Tunning

Основной интерес: Llama 3.1 8B, QLoRA/SFT/DPO и узкая специализация стиля.

## Lightweight Role-Playing Game Design Framework Based on Large Language Models

SAGE / Artificial Intelligence for the Arts and Media: https://journals.sagepub.com/doi/10.3233/FAIA260065

Основной интерес: Director System, Actor System, environment summary и private knowledge.

## ai-gm

GitHub: https://github.com/sigco3111/ai-gm

Основной интерес: layered memory, summaries, retrieval и schema-driven game state.

## Cogitator

GitHub: https://github.com/Pr0degie/dungeonmaster

Основной интерес: NPC memory, false beliefs, agendas, consequence clocks и consistency guard.

## Long-horizon DM

Harvey Tuch: https://h-tu.ch/blog/dungeon-master-long-horizon-agent/

Основной интерес: long-horizon context management, storyline JSON, stable fact keys и phase compaction.

## Hierarchical RPG content generation

arXiv: https://arxiv.org/abs/2604.25482

Основной интерес: иерархическая генерация world -> NPC -> PC -> quest -> quest expansion с передачей структурированного состояния.

## Предварительная оценка доказательности

Наиболее сильны для архитектурных выводов результаты, где опубликованы реальные датасеты, структурированное состояние и воспроизводимые пайплайны.

Заявления о качестве GMing, основанные на маленьких пользовательских head-to-head тестах, следует считать предварительными.

Этот репозиторий фиксирует исследовательские находки, а не проводит систематический meta-analysis.
